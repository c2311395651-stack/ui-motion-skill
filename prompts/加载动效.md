# 加载动效 · 4 个提示词

对应抖音视频：第04期 4个加载动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"加个 loading"，AI 多半做成白屏转圈，内容到了一下子全蹦出来。

---

## 01 骨架屏扫光（Skeleton Shimmer）
常见写法：加载时显示一个转圈 loading → 转半天圈，然后一下子全蹦出来

```
做一个信息流加载：先显示和真实内容形状一样的骨架屏（圆头像、标题条、图片块，尺寸和位置跟真实卡片一致），所有骨架共用一道柔和的斜向光带，每 1.5 秒从左往右扫过；数据到了以后，按头像、标题、图片这些块从上到下每块错开 60ms 依次浮现（淡入 + 上移 8px），骨架同步淡出，整页不跳动、不闪白。
```

## 02 图片模糊到清晰（Blur-up Image）
常见写法：做一个图片墙，加载图片 → 先白一块，图片突然砸下来，版面跳动

```
做一个照片墙：每张图先用同色调的模糊小图占位（主色底 + 20px 高斯模糊），原图加载完后从模糊慢慢变清晰，同时从 1.04 倍轻轻缩回 1 倍，约 500ms；图片框尺寸提前固定，加载前后布局不跳；离进入屏幕还有约 300px 时才开始加载。
```

## 03 滑到底加载更多（Infinite Scroll）
常见写法：做一个滑到底自动加载更多的列表 → 卡一下，一堆内容突然塞进来

```
做一个商品列表，滑到离底部还剩约一屏时就提前加载下一页；底部显示 3 个依次跳动的小圆点；新商品卡片每张错开 50ms，从下方 24px 处滑上来并淡入，约 0.45 秒，像传送带接上；加载期间滚动不卡、位置不跳；最后一页显示"没有更多了"。
```

## 04 AI 流式回复（Streaming Reply）
常见写法：做一个 AI 聊天，回复用打字机效果 → 干等几秒没反应，字一个个蹦，页面不跟着走

```
做一个 AI 聊天回复：发送后立刻出现回复气泡，里面 3 个小点呼吸跳动表示"正在思考"；开始回复后按词（中文 2–4 个字一段）一段段淡入，每段从透明、4px 模糊变清晰，末尾一个闪烁光标跟着走；气泡高度平滑长高，页面平滑跟随到底部；用户手动往上滑就停止跟随，滑回底部再恢复。
```

---

小提示：想要更像手机 App，可以在最后加一句"深色主题，按 390×844 手机尺寸，鼠标滚轮和手指滑动都能用"。

装了 skill 的话，直接说"用 ui-motion 给这个列表加载加上骨架屏"即可，AI 会按动效库里的完整参数实现。
