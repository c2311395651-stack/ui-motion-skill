# UI/UX动效交互 · 让 AI 做出高级交互动效

给 AI 编码助手（Claude Code、Codex、Cursor 等）用的动效技能包。
装上之后，AI 做界面时会自动加上有细节、有手感的交互，而不是"点一下就硬切"。

动效库和提示词会跟着抖音视频每期更新。

## 安装

```bash
npx skills add https://github.com/c2311395651-stack/ui-motion-skill
```

## 使用

装好后，在对话里直接说：

> 用 ui-motion 给这个页面加上弹出菜单
> 做一个旅行 App 的目的地列表，卡片点开要有展开动画

AI 会先说明它打算加哪些动效，你确认后才开始写代码。

## 不装也能用：每期视频的提示词

每期视频里的提示词都整理在 [`prompts/`](prompts/) 文件夹，复制发给 AI 就能用。

| 期 | 主题 | 提示词 |
|---|---|---|
| 第01期 | 2 个弹出交互：按钮长出菜单、卡片展开详情 | [弹出交互.md](prompts/弹出交互.md) |
